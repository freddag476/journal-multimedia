# EVS 1

## Gael à la plage

Dessin de Gael (Dark Souls 3) à la plage.
J'ai utilisé une image libre de droit pour le fond, et j'ai dessiné le personnage. j'ai utilisé différents types de calques (multilplié, overlay) a différentes opacités par dessus le dessin de base pour donner l'impression qu'il se trouve réellement dans l,environnement avec le bon éclairage.
