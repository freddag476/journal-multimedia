# EVS 3

## Paysage sonore pour le projet final.

Pour le projet final, nous allons faire une animation sur la chanson "The Other Side" du film The Greatest Showman. cette chanson incorpore déja plusieurs effets sonores, alors j'en ai rajouté a certain moments pour marquer des actions significatives dans l'animation (portes qui ouvre ou qui ferme, bruits de pas, bruits d'impacts lorsqu'un geste bruyant se fair (par exemple: un coup, un saut, un papier qui se froisse ou un cheval qui soufle). J'ai aussi ajouté une introduction sonore pour contextualiser la scène dans laquelle la chanson vas jouer.
