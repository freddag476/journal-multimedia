# EVS 3

## Paysage sonore pour le projet final.

Pour le projet final, nous allons faire une animation sur la chanson "The Other Side" du film The Greatest Showman. cette chanson incorpore déjà plusieurs effets sonores (on peut les entendre a 34 secondes dans l'audio) , alors j'en ai rajouté d'autres en tentant d'émuler le même style a certain moments pour marquer des actions significatives dans l'animation (portes qui ouvre ou qui ferme, bruits de pas, un cheval qui souffle, bruits d'impacts lorsqu'un geste bruyant se fait (par exemple: un coup, un saut, un papier qui se froisse, etc). J'ai aussi ajouté une introduction sonore pour contextualiser la scène dans laquelle la chanson vas jouer.
